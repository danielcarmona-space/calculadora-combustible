Consultas e incidencias

Para mantener esta versión pública sin nombres, correos, teléfonos u otros datos personales visibles, no se publica un formulario ni una dirección de contacto personal.

Información que puedes facilitar

Si reportas una incidencia por el canal público asociado al proyecto, evita incluir información personal, ubicaciones exactas, matrículas, números de teléfono, documentos de identidad u otros datos sensibles.

Antes de enviar un problema

Indica la página afectada, el navegador, el tipo de dispositivo y los pasos para reproducir el fallo. Para problemas con precios de carburantes, incluye la estación y el tipo de combustible, pero no datos personales.
