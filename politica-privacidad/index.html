Política de privacidad

Qué datos utiliza RutaFuel y cómo funciona la geolocalización y la analítica.

InformaciónAviso legalPrivacidadCookiesContacto

Principio general

RutaFuel no requiere crear una cuenta ni solicita nombre, dirección postal, teléfono, documento de identidad u otros datos personales para utilizar las calculadoras.

Datos introducidos en calculadoras

Las cifras de distancia, consumo, precio, peajes, pasajeros o energía se procesan en el navegador. La web no dispone de un sistema propio que almacene esos valores.

Geolocalización

El planificador y la opción de ordenar gasolineras por distancia pueden solicitar la ubicación del dispositivo. El navegador pide permiso de forma explícita. RutaFuel usa la coordenada durante la sesión para hacer el cálculo y no la guarda en una base de datos propia.

Servicios externos

Al utilizar mapas, rutas o precios, el navegador puede realizar solicitudes técnicas a proveedores externos. Como en cualquier conexión web, esos proveedores pueden recibir datos técnicos como la dirección IP. Consulta sus políticas antes de usar esas funciones si necesitas un nivel de privacidad específico.

Analítica

Google Analytics solo se carga después de aceptar voluntariamente la analítica en el aviso de privacidad. Si eliges continuar sin analítica, RutaFuel no carga el script de Google Analytics desde esta web.

Almacenamiento local

La preferencia de analítica se guarda en el almacenamiento local del navegador para no volver a preguntar en cada página. Puedes borrarla eliminando los datos del sitio desde la configuración del navegador.
